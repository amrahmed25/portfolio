## 👋 Overview

This repository contains the source for my personal portfolio website. It is designed to give recruiters, clients, and fellow developers a simple way to explore my projects and access related demos.

## ✨ Highlights

- Personal portfolio landing page.
- Visual presentation of selected projects.
- Project imagery to make work easier to explore.
- A single destination to share when applying for roles or freelance opportunities.

## 🧰 Tech Stack

The repository currently contains a standalone `index.html` page and image assets. The core presentation is built for the browser using web technologies.

- HTML
- CSS
- JavaScript (where included in the page)

## 🖥️ Run Locally

```bash
git clone https://github.com/amrahmed25/portfolio.git
cd portfolio
```

Open `index.html` in your browser. You can also use the VS Code Live Server extension for local preview.
